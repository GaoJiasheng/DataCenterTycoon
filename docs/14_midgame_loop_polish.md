## 2. 中期循环核心问题（M 系列，本轮主体）

### 2.1 告警系统：通知不分级、不聚合（M1/M2，P0）

**实拍**：故障扳手、续约卷轴两种世界角标都是深蓝底小圆，不呼吸、不分级；HUD 运营徽标数字含义混杂（事件+续约混算），故障发生时 HUD 无任何红色信号。

| 修法 | 细节 |
|---|---|
| 角标语义分色 | 故障=红底扳手+呼吸脉冲（每 1.2s scale 1↔1.1）；续约=金底卷轴；行情加成=绿底📈（见 M8）；老化可退役=橙底时钟。世界角标是中期玩家的主要信息源，必须一眼分诊 |
| **待办队列（本轮核心新设计）** | 运营按钮升级为「待办中心」：徽标 = actionable 事项总数（故障 N + 续约 N + 可退役 N），故障存在时徽标转红。点开后第一屏是**待办列表**（原四宫格降为第二屏或列表底部）：每行 = icon + 描述 + 一键直达按钮（「计算机柜故障 · 标准机房 → 去维修」「免费换约窗口 · 1h59m → 去换约」「币价暴涨进行中 → 看行情」）。行点击直接深链到对应抽屉/页面。这是中期日常循环的主动线，对标一线 tycoon 的任务清单 |

### 2.2 续约窗口不可见（M4/M5，P0）

**实拍**：触发免费换约窗口后打开该机房抽屉——头部无提示、「签订合约」按钮无变化，玩家只能碰运气发现。设计上的核心回访钩子（06 号 P0-3）在 UI 上是哑的。

- 「签订合约」按钮在续约窗口内改为**金色高亮**：「免费换约 · 剩 1h59m」，倒计时实时；
- 抽屉头部副标补当前客户：「挖矿客户 · 供电正常」（M5：现在只显示 $162/月，不知道签给谁——换约决策的基础信息）；
- 世界续约角标点击直达合约 tab（当前进抽屉后还要再点一次）。

### 2.3 决策点缺信息（M3/M6，P0/P1）

**故障操作单（M3，P0）**：三个按钮都不披露代价与效果。修正：
- 「维修 · $15 · 约 18 分钟」（费用=购置价 5%，耗时区间中值）；
- 「看广告 · 立即修复（今日 3/4）」；
- 「钻石立修 · 2💎」；
- 「退役」改为「拆除机柜 · 回收 $150」置底降权重（当前与机房「退役」用词冲突且易误触）。

**退役决策（M6，P1）**：退役按钮已显示 +$910，补一行权衡信息：「回收金随老化每天递减 · 当前月收入 $110」；87% 后（盈亏平衡点附近）按钮转橙提醒。数据全部来自现有 `Rules.retirement_value` / `datacenter_monthly_income`，UI 只读。

### 2.4 行情红利无反馈（M7/M8，P0/P1）

**实拍 M7（P0）**：地图中央悬浮一枚 ~110u 的巨型金色机柜硬币，语义不明（正常金币 42u）——排查来源：若是「行情加成」标记则改为 44u 绿底📈角标；若是金币动线的异常个体则修尺寸参数。任何世界元素不得超过建筑高度的 1/3 且不得驻留在车道上。
**M8（P1）**：吃到事件加成的机房没有任何反馈——挖矿机房在「币价暴涨」期间应显示：世界角标绿底📈、抽屉头部「币价暴涨 ×2.5 生效中 · 剩 3h50m」。这是「看行情调结构」玩法的正反馈闭环，没有它玩家感知不到调仓的收益。

### 2.5 通路断点（M9/M11，P1）

- **M9**：离线大事记三行（1·故障 / 1·行情 / 1·寿命）是死文本——每行变为可点：关闭弹窗后直达对应场景（故障→该机房抽屉、行情→行情页、寿命→该机房）。「回来 → 看到问题 → 一键去处理」是回归体验的黄金三步；
- **M11**：事件横幅「点击调整合约」点击行为需明确：多座机房时跳**行情页事件卡**（那里已有「查看我的合约」入口），而非任意机房；横幅可手动划掉（右滑 dismiss）。

### 2.6 观感杂项（P2）

- M10：离线弹窗每次都撒彩纸屑会腻——仅当收益 > 上次余额 20% 时播放；
- M12：同 tier 建筑贴图完全相同，三座 T1 并排重复感明显——A2 扩展每 tier 第二变体（或运行时镜像翻转 + 色相 ±5°，零素材成本先试）。
