## 2. FTUE 场景协议重构（B 系列，本轮核心）

### 病根

流程审计实拍的四个断裂点：

1. **建设等待期指令错误**（s1）：机房还剩 4m59s 才建成，教练已在喊「安装变压器」——当前无事可做，指令与现实脱节；
2. **目标解析只认控件、不认世界**（所有者截图 + s1_map）：`install_power` 只找抽屉里的 `PowerSlot`，抽屉没开就退化成钉在屏幕底部的纯文字气泡——没箭头、没聚光灯、不知道点哪；
3. **步骤切换不清场**（s5）：「购买下一块地」步骤时机房抽屉还开着，聚光灯挖洞挖在棋盘右侧两格上，手指指着空气；
4. **动作不可用时照常下指令**（s6）：买地后立即进入退役教学，教练说「机房已经老化」——实际寿命 0%、退役按钮根本不存在，玩家将卡在此步 **约 14 小时**无任何可执行操作。

### B1 · 步骤场景协议（结构性修复）

`tutorial.json` 每步新增 `context` 字段，`main_view` 在**步骤激活时**执行统一清场：

```
context: "map"    → dismiss 所有 sheet/抽屉 → 导航回 map → FxLayer.clear() → 相机聚焦目标 → 解析目标
context: "drawer" → 确保抽屉开在目标机房（未开则先指向世界建筑，见 B2）→ FxLayer.clear() → 解析目标
context: "dormant"→ 收起聚光灯与指令气泡，仅保留角落小提示（见 B4）
```

各步 context：welcome=map / power=drawer / first_rack=drawer / contract=drawer / cooling=drawer / buy_plot=**map** / retire=dormant→drawer / standard=map。

### B2 · 两段式目标（世界对象作为第一段）

`context=drawer` 且抽屉未打开时：目标 = **世界层该机房的建筑矩形**（park_map 新增 `building_rect(dc_id)`），气泡跟随建筑、箭头指向建筑、聚光灯挖洞在建筑上，文案自动加前缀句「点开机房——」；玩家点击建筑进入抽屉后，目标切换为第二段（PowerSlot / RackSlot0 / 合约 tab）。彻底消灭「钉底纯文字模式」——该模式仅保留给 `dormant`。

### B3 · 建设等待期（节奏修复，二选一，推荐①）

① **教学期 T0 建设时长 300s → 30s**：`buildings.json` 加 `tutorial_build_seconds`（仅 dc_t0 生效，`start_datacenter_construction` 在教学未完成时采用）——放置游戏首日黄金节奏是 90 秒内点亮机房；数据字段属玩法层数据，**需所有者确认**（不改公式只改教学期时长，06 号文档纪律内的低风险项）；
② 保守方案：welcome 与 power 之间插入过渡步「工地施工中——看个广告立刻完工，或稍等片刻」，目标=队列按钮，广告完成/自然完成均推进。

### B4 · 退役步骤事件化（消灭 14 小时卡壳）

buy_plot 完成后 retire 步进入 `dormant`：气泡显示一次「集装箱机房寿命只有一天，等它老化时回来上最后一课」后收起为 HUD 角落小提示（教练头像 + 红点）；订阅现有 `datacenter_entered_aging` 事件，触发时教学恢复为 `drawer` context（指向退役按钮）+ toast。**规则固化：任何步骤在其动作不可执行时，禁止显示行动指令文案。**

### B5 · 文案与状态一致性

- 「机房已经老化…」只在 progress ≥ aging_start 时出现（B4 已保证）；
- 「需要先升级变压器」显示条件修正：仅在已有供电且选购更高阶时；未装电时文案为「先安装变压器」；
- 「供电 0/0」→ 未装电显示「未安装供电」。
