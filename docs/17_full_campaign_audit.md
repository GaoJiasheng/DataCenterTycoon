# 17 · 全流程通关审计（内测前）

目标：不只验证新手教程，而是**把整局游戏打完**——确认内测玩家从全新存档一路能走到时代 3 和第一次上市重组，中途不会卡死、不会状态错乱、不会遇到走不出去的界面。

## 1. 手段

新增 `tests/full_campaign.gd` / `.tscn`。它挂载真实 `main.tscn`，按**游戏月**推进（每月 7200 秒，分 4 段推进），每个月都：

- 刷新真实 UI，跑一遍不变量断言；
- 像玩家一样点掉挡路的模态框（时代号外、离线结算）；
- 执行一轮"玩家操作"：修故障 → 退役到期机房 → 补供电/制冷/机柜 → 签约 → 建新机房 → 买地 → 升网络。

模拟玩家的策略刻意写成"一个称职但不作弊的玩家"：

- 先修故障再花钱——坏掉的机柜不产出，修它永远比它损失的收入便宜；
- 留一年的运维费当储备金（`_spare_cash()`），不把现金花光；
- 只在能配齐（外壳 + 变压器 + 一台冷机 + 3 台机柜）时才开新机房，不建空壳；
- 机柜只放在**制冷压得住**且**变压器供得上**的槽位——过热只有一半收入，没电则完全没有收入；
- 所有地都用起来了才买下一块。

跑到"时代 3 且累计建成 20 座"就停，然后验证离线返回、上市重组，以及重组之后能否重新开局。

## 3. 过程中暴露并已修复的问题

### 3.1 行情横幅会压在页面标题和顶部信息带上（已修）

`_show_market_banner()` 把横幅停在固定的 y=130，并且不管当前在哪一页都直接弹出。结果：

- 在行情 / 科技 / 商店页，横幅盖住页面自己的标题栏和分页标签；
- 在地图上，横幅和「世界新闻条」「园区翻页器」「园区铭牌」互相重叠，看起来像三条错位的黑条叠在一起。

修法（`ui/main_view.gd`）：

- `_market_banner_would_be_buried()`：只要不在地图页，或者有整屏模态（离线结算 / 时代号外 / 破产），就把横幅挂起，等回到地图再放出来；导航离开地图时直接收掉在场的横幅。抽屉和操作面板不算——它们在下半屏，不会遮住横幅。
- `_market_banner_rest_y()`：停靠位置改成实测「新闻条 / 翻页器 / 园区铭牌」三者的全局矩形下沿再留 12px。这几个控件在安全区 stage 里，横幅挂在视图上，两者坐标系不同，必须用全局矩形量，不能直接比 offset。

### 3.2 行情横幅会无限堆叠（已修）

`_present_market_banner()` 先 `banner.name = "MarketEventBanner"` 再 `add_child()`。上一条横幅是 `queue_free()`，本帧还在树里，于是 Godot 给新节点自动改名成 `@Button@7042` 之类。改名之后，靠名字查找的去重和收尾逻辑**再也找不到它**——横幅不会被替换、离开地图也不会被收掉，只会一条条叠上去。

在真机上两个行情事件同时开始/结束时就会触发；在加速跑的回归里，一局能叠出 9 条盖满半个屏幕。

修法：横幅改用 `market_event_banner` 分组追踪，`_retire_market_banners()` 先 `remove_child()` 再 `queue_free()`，让名字立刻空出来。

回归断言写进了 `full_campaign`：地图上同时存在的横幅数必须 ≤ 1，其停靠矩形不得与顶部三件套相交，非地图页不得有横幅存活。

## 4. 一个不是 bug 但值得记住的设计事实

前几轮模拟里，模拟玩家反复在第 8～10 游戏年破产，卡在「现金 0 / 收入 0 / 全部机柜故障」的死循环里出不来。逐一排查后确认**不是数值问题，而是三个操作失误**，任何一个都足以让真人玩家滑进同一个坑：

1. **不修故障**——故障机柜完全不产出，攒够三四台整个机房就归零；
2. **买了供不上电的机柜**——`powered_slots()` 是按容量贪心分配的，超出变压器容量的机柜纯属打水漂；
3. **建了配不齐的空壳机房**——空机房照收运维费。

这三条都是"玩家做错了游戏会惩罚你"，惩罚也确实是设计意图（`arrears_income_multiplier: 0.5` 就是为此存在的）。但滑进去之后**没有自愈路径**：收入 0 → 修不起 → 收入还是 0。目前的兜底是欠费横幅上的「看广告救援」和破产后的重开公司，机制上说得通。

如果内测反馈说"玩着玩着突然就没钱了"，优先看的不是数值表，而是这三处的**引导是否够强**：机柜安装时有没有明确拦住超出供电容量的选择，空壳机房有没有持续提示"该装设备了"。这一版没有动这部分——它属于设计取舍，不是缺陷。
