# 26 · 律师咨询事实清单

> **本文不构成法律意见。** 本文只整理截至 2026-08-31 仓库可验证的项目事实与拟咨询问题；不判断权利归属、合规充分性、税务结果、条款可执行性或任何法域下的法律结论。

## 1. 项目与发行事实

- 项目是 Godot 4.7 制作的竖屏、iPhone-only 放置经营手游；iPad 仅以兼容模式运行，不作为 1.0 发布目标。
- 当前工程包含简体中文与英文两套玩家可见文本。
- build 11 已上传 TestFlight；本批次不发布新 build。
- 计划发行区域为中国大陆以外。具体国家/地区清单尚未在本文件中确认。
- 产品名称、发行主体、隐私政策 URL、支持 URL、支持邮箱与生效日期仍是所有者待填的发布身份字段。本文件不替这些字段给值。
- 根目录 `LICENSE` 将项目特有代码、文档、美术、音频和设计声明为专有、All Rights Reserved；第三方组件继续按各自许可证处理。

## 2. 技术与第三方组件事实

- 游戏使用 Godot Engine 4.7。应用内“第三方与许可”页在运行时调用 `Engine.get_license_text()` 与 `Engine.get_copyright_info()`，展示引擎及其返回的内嵌组件版权和许可文本。
- UI 使用 Baloo 2 与 Resource Han Rounded CN。两份 SIL Open Font License 1.1 全文随包并可在应用内阅读。
- Resource Han Rounded CN 的上游 v1.910 发行包、可变母版和运行时子集校验记录见 `assets/fonts/README.md`；Baloo 2 的上游版本与母版下载记录目前标为待确认。
- 第三方与许可数据源为 `data/attributions.json`；逐项资产证据与未知项见 `docs/26_provenance.md`。

## 3. 美术与音频事实

- 运行时美术清单含 180 张图。仓库 prompt 记录称这些图由 Codex 内置 `imagegen` 逐件生成，并记录了统一 prompt、部分逐件 prompt、生成输出路径和本地后处理流程。
- 仓库没有保存底层生成模型/服务主体、每次生成时适用的服务条款版本、账号/订阅主体等完整证据；这些项在来源台账中明确写为“待确认”。
- 运行时音频清单含 23 个 cue。生成脚本与音频规格声明为项目内确定性合成，不使用第三方 samples、loops 或 preset recordings。
- 音频作者/委托关系、权利主体与署名策略尚未由所有者书面确认，来源台账没有把“无第三方采样”提升为权利结论。

## 4. 商业化与数据处理事实

- 商品配置含消耗型钻石、礼包、离线收益扩展与去广告权益；iOS 发行计划使用 StoreKit/IAP 插件，插件描述符仍是发布门禁中的待交付项。
- 游戏含可选激励广告入口；当前设计不要求观看广告才能继续核心经营流程。
- 当前隐私政策模板列出的项目数据类别与实际 SDK/线上服务清单，仍需在接入最终 IAP、广告、崩溃分析或其他服务后逐项复核。
- 设置页可在应用内阅读隐私政策、服务条款、支持说明和完整第三方许可；托管隐私/支持 URL 仍是 App Store Connect 的外部交付项。

## 5. 拟咨询问题

### 名称、商标与品牌

1. 在 P01 定名前，应在哪些目标发行地区做哪些层级的商标与应用名称检索？
2. App Store 已存在近似或同名应用时，名称、图标、商店文案和域名应如何降低混淆风险？
3. 是否建议注册文字商标、图形商标或二者；应以个人还是拟设公司申请？

### 著作权、AI 生成内容与资产证据

4. 以当前 prompt、生成记录、人工筛选和后处理证据，项目在各目标法域中哪些部分可能具备著作权保护，哪些部分需要补充人类创作记录？
5. AI 生成美术的可版权性、排他性和可转让性在目标法域中分别存在哪些不确定性？
6. 对 imagegen 生成记录，应补存哪些服务条款版本、账号证明、时间戳、原图与编辑记录，才能形成更完整的商用权证据链？
7. 音频为本地代码确定性合成时，应如何记录作者、委托/雇佣关系、源代码与母带，以便证明权利主体？
8. 是否值得办理软件或美术/音频相关的著作权登记；如办理，应以什么作品分类和什么主体申请？

### 发行主体、合同、责任与税务

9. 个人开发者与公司主体发行在合同责任、消费者索赔、税务、收款和后续资产转让方面分别需要评估什么？
10. 当前 ToS/EULA 模板需要哪些强制披露、消费者权利保留、退款说明、责任限制、争议解决与管辖条款，才能适配实际发行地区？
11. 如果未来由个人迁移到公司主体，商标、代码、美术、音频、App Store 应用和用户合同应如何留存并转移？

### 隐私、广告、IAP 与未成年人

12. 最终接入的 StoreKit、广告、崩溃分析或客服服务分别会触发哪些隐私披露、同意、跨境传输或数据处理协议要求？
13. 可选激励广告在目标地区需要哪些广告标识、未成年人保护、频次/同意与第三方 SDK 披露？
14. 钻石、礼包、去广告与离线权益的定价和描述，应如何满足各目标地区的消费者保护、虚拟物品、自动交付与退款规则？
15. 当前年龄分级草稿、数据中心/挖矿题材与广告/IAP 设计，是否需要额外的未成年人限制或家长提示？

### 开源与字体许可

16. 应用内动态展示 Godot 及内嵌组件版权/许可、并随包发行 OFL 正文的做法，是否还需在商店页、网站或下载材料中增加归属？
17. 对 Baloo 2 上游版本证据缺口，应补取哪些官方来源文件与哈希记录；现有运行时文件在补齐前是否需要暂停发行？
