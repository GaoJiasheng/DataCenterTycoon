## 已锁定的决策

### 产品定位
| # | 决策 | 说明 |
|---|---|---|
| D01 | 类型：放置 + 轻布局混合 | 数值放置做骨架，机房内部轻布局做表现层；不做复杂流水线 |
| D02 | 平台：iOS App Store | 竖屏手游，多尺寸兼容（iPhone 全系为主，iPad 可用即可） |
| D03 | 引擎：Godot 4 | 沿用所有者已有的 Godot + iOS 发行管线经验 |
| D04 | 市场：中英双语 | 面向中国大陆以外的所有 App Store 区域发行 |
| D05 | 目标：兴趣驱动 + 小额营收 | 不追求抢占市场，控制范围，确保能上线 |

### 核心玩法
| # | 决策 | 说明 |
|---|---|---|
| D10 | 单个机房内部网格为 **3×3** | 手机操作友好；9 个机柜槽位 |
| D11 | 冷却/供电**不占**网格格子，作为机房外挂件 | 供电：接上后机房点亮，无电则暗灰；冷却：有冰霜/风的视觉特效 |
| D12 | 冷却采用**轻邻接制**（方案 B） | 冷却单元挂在机房四条边上，只覆盖所贴的那一行/列（3 格）；供电为机房级容量，不看位置 |
| D13 | 地图总量无上限，按有限容量园区分页扩张 | 园区 1 为 6 位标准型，园区 2 起为 8 位扩展型并重复；园区容量只负责信息分组，不构成全局建筑上限。用缓增幂函数地价 + 最高 8% 园区溢价 + 现金流压力做经济阀门，确保百座规模仍可达 |
| D14 | 机型三类：计算型 / 存储型 / GPU | 对应「种什么菜」的选择 |
| D15 | 客户四类：云厂商 / 互联网厂商 / GPU 厂商 / 挖矿 | 合约以**机房**为单位签订；不同阶段各行业收入随行情事件波动 |
| D16 | 机房会老化并退役 | 寿命约 5 游戏年；正常退役是收益更高的收割，报废后可免费清理并回收折价残料；时代 2 可解锁 95% 自动退役 |
| D17 | 退役按**每座机房独立计龄** | 不做全局统一退役潮；批量建设自然涌现「退役潮」 |
| D18 | 新手第一座机房为「集装箱机房」，寿命 1 游戏年 | 让玩家第一天完整体验建→赚→老化→退役全循环 |
| D19 | 转生（上市重组）**后期才出现** | 累计建成 ≥ 20 座机房后才解锁入口；效果：全部资产清算折现加入现金，盘面重置，获得永久收入倍率 |
| D20 | **软破产**：现金流断裂不再 Game Over | 现金流断裂先进入「欠费」预警；持续未清偿时触发「银行接管」，自动变卖资产抵债并继续经营，永不清档 |
| D21 | 时间换算：**1 现实天 = 1 游戏年** | 详见 02_economy；游戏时钟离线继续走，离线收益结算有上限 |
| D22 | 合约**签约锁价** | 锁定值为合同期内已知行情的时间加权平均：不含日噪声、只计签约时已生效事件；实时行情只影响新签与改签，战略约另保留 ×2.5 封顶 |
| D23 | **轻松离线原则** | 离线期间任何系统不得让玩家资产或收入变得比离线前更糟；老化是正常损耗，并由离线冻结/自动退役兜底 |
| D24 | 故障是**降效事件** | 故障只降低产出且超时自动修复；玩家干预的作用是加速恢复，不是避免永久停产 |
| D25 | 公司路线图是**永久里程碑** | 只奖励既有经营行为，奖励可补领且永不过期；不使用日常任务或限时强迫 |
| D26 | 每个园区可免费选择一种**经营定位** | 定位需由真实布局条件激活；允许随时免费切换，不惩罚试错 |
| D27 | 客户关系只增长不衰减 | 持续服务解锁关系加成与战略长约；可选 3/6/12 游戏月，合约仍签约锁价、到期自动续约 |
| D28 | 行情页保留**决策复盘** | 记录玩家当时的锁价和之后的行情变化，只帮助学习，不给正确答案或追溯惩罚 |
| D29 | 转生提供董事会专长与公司纪念册 | 每次传承获得一个永久策略点，清算前保存本局经营复盘；所有分配可免费重置 |
| D33 | 企业典藏只记录真实发现 | 设施、客户、行情、传承按实际遇见点亮，整套奖励一次性补领且永不过期 |
| D34 | 批量建造/配置蓝图暂缓 | 所有者本轮明确先不做；本次元进度改造不得夹带批量操作系统 |
| D35 | 询价单永不过期 | 具体客户带条件来单，接单沿用合约系统并附加溢价与签约金；询价不设现实倒计时，只在接受或婉拒后补位 |
| D36 | 棋盘成组加成 | 整行或整列三台同类型机柜构成成组，成员收入 +10%；一台机柜最多享受一次，不叠加 |
| D37 | 稀有行情与战略约锁价封顶 | 低权重稀有事件进入行情池；稀有事件先按各档合同期限折算，询价溢价随后加入，12 月战略约最终再封顶 ×2.5；灵活与标准约不封顶 |
| D38 | 工程部扩编按局重购 | 建设队列容量可通过科技从 2 逐级扩到 5；扩编随转生重置，跨局财富由重新购买扩编转化为建设速度 |

### 经济与商业化
| # | 决策 | 说明 |
|---|---|---|
| D30 | 双货币：现金（$）+ 钻石（💎） | 现金游戏内赚取，是经济纽带；钻石以付费获取为主、少量免费赠送 |

## 明确不做（1.0 范围外，未经所有者同意不得加回）

- 电价峰谷 / 负载调度
- PUE 数值系统
- UPS、柴油发电机等冗余设备
- 上架率、机柜密度、Tier 等级认证
- 复杂流水线（传送带式生产链）
- 机房间网络拓扑玩法（1.0 简化为「接入等级」，见 01_game_design）
- 限时决策窗口（所有需要玩家拍板的事项必须等玩家上线，不设现实时间倒计时）
- 联网后端 / 云存档（纯单机 + 本地存档）
- Android 版本（先 iOS）
