## 1. 诊断：为什么「挤」

第二轮把美术资产全面接上后，出现了新的系统性问题。放大取证（`/tmp/crop_*.png`）确认五个根因：

### 根因 1 · 光泽按钮资产被当成数据卡用（最严重）

合约页客户卡：一个为**单行 CTA 文字**设计的光泽药丸（btn_primary），被塞进了 5 行数据（名称·状态 / 倍率·涨跌 / 三系数 / 预计收入 / 换约费）。容器不会随内容长高 → **文字行互相叠印**，且深色小字压在高饱和绿色高光上。这是「文字互相折叠」的直接来源。同病：挖矿卡、锁定卡、语言按钮、棋盘 tab。

### 根因 2 · 装饰框架层层嵌套

当前一屏的框架层级：蓝色玩具外框（页面）→ 深色卡片框 → 管状行框（设置页每一行都套了一个拉伸变形的九宫格框）→ 光泽按钮框。**四层装饰**，每层吃掉 12–40u 边距，内容区被压缩到不足画布宽度的 70%，然后文字被迫缩小、省略、换行。一线游戏只有**一层**装饰框架（页面级），内部全部是扁平色块分组。

### 根因 3 · 固定高度 + 内容超高 = 裁剪 bug 群

棋盘电力条、合约确认按钮、欠费横幅进度条、教练气泡末字——全部是「容器写死高度/Sheet 写死高度，内容 minimum_size 超出」导致的底边裁剪。这是同一个 bug 的六次复现。

### 根因 4 · 文字对比度无规则

彩色小字压彩色光泽底（绿底红字、蓝底黄字、紫底紫字）、白字被高光带吞（主 CTA「建造机房」）、描边只有 2px 太细。每处单看是小事，合起来就是「看什么都费劲」。

### 根因 5 · 桌面窗口配置错误

`project.godot`：`window_width_override=880 / window_height_override=1912`。1912 高的窗口在任何笔记本屏幕上都放不下，macOS 强行钳制窗口后内容被非整数比例缩小——**所有者在电脑上看到的每一个像素都比设计尺寸更小更糊**。这放大了上述所有问题。

> 结论：这不是「再修一批 bug」的问题，而是要**立规矩 + 按规矩重排每一屏**。规矩见 §2，重排见 §4。

## 2. 五条铁律（本轮起全局生效，违反即打回）

**法则 1 · 一层装饰**
每屏只允许一层装饰性框架 = 页面/Sheet 的外框（蓝色玩具框保留，它是风格担当）。框内一切分组用**扁平深色圆角色块**（`Color(0,0,0,0.22)`，无边框或 1px 低透明度描边）。管状行框、卡片描边框、嵌套光泽框全部拆除。光泽药丸按钮（btn_*）只允许出现在**单行文字的可点按钮**上，任何承载 ≥2 行内容的元素禁止使用。

**法则 2 · 内容撑高，禁止写死**
任何含文本的容器高度必须由 `get_combined_minimum_size()` 驱动（VBox/HBox 自然布局）；Sheet 高度 = `min(内容高度 + 边距, 画布 88%)`，超出部分滚动。全局删除「固定高度 + 多行 Label」的组合。这一条直接消灭全部六处裁剪与叠印。

**法则 3 · 排版基准（翻倍呼吸感）**
- 正文最低 **24u**（12pt），辅助文字最低 **20u** 且只允许出现一层；删除 18u 档。
- 行距：Label `line_spacing ≥ 6u`；相邻文本块间距 ≥ **12u**。
- 内容边距：页面框内 **32u**，色块分组内 **24u**（现状 12–20u，全部翻倍）。
- 分组之间垂直间距 **24u**，组内元素 **12u**——「组间 > 组内」是呼吸感的来源。
- 每张信息卡**最多三个层级**：标题（28u 粗体）/ 主数值（32u 数字字体）/ 一行辅助（20u）。超出的信息进长按 tooltip 或详情页，不许再塞第四行。

**法则 4 · 文字对比度只有两种合法组合**
① 白字（`#FFFFFF`）+ ink 描边 **4px**——用于一切彩色/光泽/世界层背景；
② 深字（`COLORS.ink`）+ 米白底——只用于 `panel_main` 浅色纸面（对话、报纸演出）。
调用点**禁止**把按钮/卡片文字覆盖为任何彩色；彩色只用于独立的数值 Label（绿涨红跌等），且必须落在深色扁平底上。

**法则 5 · 每屏一个焦点**
每屏只允许一个高饱和主 CTA（绿色）；同屏其余按钮一律低饱和深蓝扁平样式。当前商店/合约/设置页满屏光泽按钮互相抢焦点，改后光泽资产只留给主 CTA 与购买按钮。

## 3. 桌面窗口修复（5 分钟，立刻做）

```ini
# project.godot [display]
window/size/window_width_override=440    # 880 → 440（0.5x，匹配笔记本屏）
window/size/window_height_override=956   # 1912 → 956
window/stretch/aspect="keep"             # expand → keep（桌面窗口拉动时不再改变构图）
```

`canvas_items` 拉伸模式下 0.5x 整数比例缩放，桌面预览清晰不糊；iOS 真机不受 override 影响。验收：在 1440×900 的屏幕上窗口完整可见、文字边缘锐利。

## 4. 逐屏重排规范

> 每屏给出结构与自查点。执行顺序按本节排列（影响面从大到小）。

### 4.1 合约 tab（重灾区，第一个做）

```
[扁平深色分组]  客户：互联网厂商        ← 24u 白
              续约窗口 · 1h59m 内免费换约   ← 20u cyan，仅此一行辅助
[客户卡 × 4，扁平深色色块，高度自适应约 150u]
  ┌───────────────────────────┐
  │ (icon 64) 互联网厂商    [服务中]徽章  │ ← 28u 白粗体 + 绿色小徽章
  │           ×1.02 ↘ -0.0%          │ ← 32u 数字字体，涨红跌绿只染数值
  │           预计 $81/月             │ ← 24u yellow
  └───────────────────────────┘
```

- 三系数（C/S/G）从卡面**移除**→ 长按卡片弹 tooltip；锁定卡只两行：名称 + 「🔒 时代 2 解锁」。
- 卡片是扁平色块 + 按下缩放反馈；**不用**光泽药丸。选中/服务中状态 = 左缘 6u 绿色竖条 + 徽章，不靠整卡换色。
- 确认 Sheet：法则 2 自适应高度，确认按钮（唯一光泽绿钮）完整可见。

### 4.2 设置页

- 拆掉每行的管状框：语言、三个开关、法律四项全部改为**扁平行**（左 24u 标签、右控件），行高 96u，行间只用 1px 分隔线（`Color(1,1,1,0.06)`）。
- 语言选择改成一个分段控件（两段，选中段深蓝底白字），不用两个光泽按钮。
- 「退出公司」是唯一红色按钮，放页尾，与上方间隔 48u。

### 4.3 HUD 顶栏

- 公司 chip：只显示 时代 icon（46u）+ 数字「1」，宽 96u，内容 HBox 排布；完整时代名进 tooltip/科技页。禁止 icon 与文字叠放。
- 资源 chip：换成简单的深色圆角胶囊（法则 1 扁平化；卷轴端帽资产弃用）：icon 40u + 数字（28u 数字字体，白）+ 右端 28u「+」。高度 72u。
- 顶栏总高从 88u 收窄到 76u，让世界多露 12u。

### 4.4 机房棋盘页

- 头部信息从 4 块减为 2 块：寿命条（含百分比文字）+ 月收入。合约信息只在合约 tab 显示。
- tab 选中态：选中 = 深蓝底 + 白字 + 底部 4u 亮色条；未选中 = 透明底灰字。**不用光泽药丸做 tab**。
- 电力条区：法则 2 自适应；条高 40u，上方留 12u。
- 冷却插槽：超出 `cooler_slots` 数量的插槽渲染为半透明锁定态（不可点，点击 toast 说明）；已装/可装/锁定三态视觉分明。
- 放置预判徽章统一 ✓（绿）/ ⚠（橙，会过热）/ ⚡（红，电力不足），删除 ×/— 徽章；非放置态清除全部高亮。

### 4.5 FTUE

- 教练气泡：法则 2 自适应高度（修「房」字裁剪）；文案压到 ≤ 姓名 20 字一行 + 正文一行。
- 手指：`ic_pointer_hand` 资产生成前，fallback 改为程序化绘制的圆头箭头（两个 Polygon2D），指向洞的上缘外 24u，**永不遮挡目标文字**。
- 挖洞描边：黄色 6px、alpha 0.6↔1.0 脉冲；暗幕维持 0.55。
- 主 CTA「建造机房」白字 + 4px ink 描边（法则 4），文字避开高光带（`art_button_box` 的 `content_margin_top` +6u 下移文字基线）。

### 4.6 行情页

- 图例 pill 底色 = 各系列色 `darkened(0.35)`、白字；加 ×1.0 虚线基准线。
- 客户走势卡按 4.1 同款扁平三层卡重排（当前卡内 4 行偏挤，删「近 7 日走势」文字，sparkline 本身就是说明）。
- 图表卡与「客户走势」「正在发生」两组之间 24u 组间距。

### 4.7 商店

- 钱包卡去边框（现在像个按钮）；分区标题 28u 粗体 + 上方 32u 间距。
- 商品卡扁平化：icon 块（96u）+ 名称/说明两行 + 右侧唯一光泽绿价格钮（宽 200u）。「最划算」丝带徽章保留，加送百分比并入名称行尾（黄色数值字）。

### 4.8 时代演出 & 欠费横幅

- 演出：奖励数字滚动结束必须定格终值；标题 key 去多余空格；解锁清单行距 12u。
- 欠费横幅：法则 2 自适应（修进度条裁剪）；「领取救急金」按钮白字描边（现紫底紫字）。

## 6. 自动化门禁：让「挤」被测试拦住

这轮问题全部通过了 30 态视觉测试——因为测试只查行高与触控尺寸。给 `visual_smoke.gd` 增加三条断言，此后任何折叠/裁剪/贴边直接红灯：

```gdscript
# A. 裁剪检测：可见文本控件必须完整落在所有裁剪祖先的可视矩形内
for label in find_children("*", "Label"):  # Button 同理
    if not label.is_visible_in_tree() or label.text.is_empty(): continue
    var rect := label.get_global_rect()
    var node := label.get_parent()
    while node is Control:
        if node.clip_contents and not node.get_global_rect().grow(1.0).encloses(rect):
            fail("clipped: %s in %s" % [label.text, node.name])
        node = node.get_parent()

# B. 叠印检测：同一父容器下两个可见 Label 的矩形不得相交（收缩 2u 容差）
#    仅检查直接兄弟——跨容器重叠由 A 覆盖大多数场景

# C. 呼吸密度检测：每个可见 PanelContainer 内，
#    子内容 minimum_size 不得超过面板自身尺寸（即内容没有被压缩）
```

外加法则 4 的规则断言：遍历可见 Button，`font_color` ∈ {白, cream} 且 `outline_size ≥ 4`。

**验收流程**：§4 每完成一屏 → 跑 30 态（断言全绿）→ 出该屏前后对比 crop 图存 `docs/ui_review/`；全部完成后所有者用 §3 修复后的桌面窗口亲自过一遍，以「不挤、能读、想点」为最终标准。
