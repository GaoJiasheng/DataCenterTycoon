# 01 · 核心玩法设计

> 阅读前置：[00_decisions.md](00_decisions.md)。所有数值的具体取值见 [02_economy.md](02_economy.md)，本文只写机制。

## 1. 一句话玩法

像种菜一样经营数据中心：**买地 → 建机房（等待建设周期）→ 挂供电/冷却 → 上架机器 → 签客户合约持续收钱 → 机房老化 → 择机退役回收 → 用更好的技术重建、并扩张更多机房**。金钱是唯一纽带：所有扩张都要现金流支撑；入不敷出会先欠费，持续未处理则由银行接管部分资产，但经营永不清档。

## 2. 三层循环总览

```
短循环（每次打开 1~5 分钟）        中循环（小时~天级）              长循环（天~周级）
┌──────────────────┐      ┌──────────────────┐      ┌──────────────────┐
│ 收离线收益(可广告×2) │      │ 建设队列：新机房/    │      │ 机房老化→退役→     │
│ 处理故障(派修/广告)  │ ───▶ │ 供电/冷却 (计时器)   │ ───▶ │ 更高代际重建        │
│ 空槽上架/合约续签    │      │ 买新地块(递进地价)   │      │ 时代演进(托管→云→AI)│
│ 看行情、切客户类型   │      │ 行情事件应对        │      │ 转生：上市重组      │
└──────────────────┘      └──────────────────┘      └──────────────────┘
```

节奏锚点（由 1 现实天 = 1 游戏年推出，详见 02_economy）：

- 标准机房建设 1~2 游戏月 = **1~2 现实小时** → 「下单、离开、回来验收」
- 标准机房寿命 5 游戏年 = **5 现实天** → 每周经历 1~2 轮完整「建—赚—退—重建」
- 行情事件持续 1~6 游戏月 = **2~12 现实小时** → 每天打开都有新行情

## 3. 世界与地图

- **视角**：竖屏，3/4 俯视（2.5D），主地图可上下滚动、双指缩放。
- **地块（Plot）**：地图逻辑上是一条可无限扩展的地块序列，视觉上按园区分页：园区 1 是 6 位（2×3）标准园区，园区 2 起是 8 位（2×4）扩展园区。所有页面复用同一组严格的左右基线，建筑保持素材原始朝向，禁止按列镜像。已有地块与下一块待购土地按行顺序填满；当前页落单时仅将末项居中，仍不是可自由摆放的棋盘。玩家通过横向园区 Tab 与集团总览管理大量机房；每页有明确边界，非当前园区停止世界层绘制但继续参与权威模拟。每块地：
  - 状态：`未购买（带价签的荒地）→ 已购买（空地）→ 建设中（工地）→ 运营中（机房）→ 报废（废墟，需清拆）`。
  - 地价按已购买地块数量作 1.5 次幂缓增，并叠加园区类型的小幅场地溢价（公式见 02_economy §4.1）；禁止几何指数在大规模阶段压过机房建设成本。
  - 单个园区有建设位上限，但园区页数无上限；当前园区满载后自动出现下一园区 Tab 与待售地块。
- **网络接入等级**（简化版网络系统）：全局属性，等级 L1~L4（10G → 100G → 专线 → 骨干节点）。
  - 花钱升级，一次性投资 + 建设周期。
  - 作用：全局收入乘数，且高等级客户（GPU 厂商、云厂商大单）要求最低网络等级。
  - 不做机房间连线拓扑（见 00_decisions「明确不做」）。

## 4. 机房（Data Center）

### 4.1 结构

一座机房 = **1 个 3×3 机柜网格 + 外挂件插槽**：

```
            [冷却位·北]
          ┌───┬───┬───┐
[冷却位·西] │ 0 │ 1 │ 2 │ [冷却位·东]
          ├───┼───┼───┤
          │ 3 │ 4 │ 5 │      [供电位]──(电缆)──机房
          ├───┼───┼───┤
          │ 6 │ 7 │ 8 │
          └───┴───┴───┘
            [冷却位·南]
```

- **机柜槽位（9 个）**：每格可上架一台机柜（计算型/存储型/GPU），也可空置。
- **冷却位（4 个，东南西北各 1）**：挂载冷却单元。**只覆盖所贴的那一行/列的 3 个格子**（轻邻接制）。角格可被两个方向的冷却同时覆盖，覆盖量叠加。
- **供电位（1 个）**：挂载供电单元（变压器）。供电是机房级容量，不看位置。
- 机房本体分**等级（Tier）**：集装箱（教学用）→ 标准 → 大型 → 超大规模，等级决定寿命、槽位解锁数、可挂冷却位数量（详见 02_economy §3）。
  - 注：低级机房不是 9 格全开——集装箱只开 4 格（2×2 视觉上仍是 3×3 网格但锁 5 格），标准开 6 格，大型起 9 格全开。锁定格显示为盖着防尘布的空位。
- **成组加成**：任意整行或整列 3 台同类型、已通电且完成安装的机柜构成一组，三台收入各 ×1.10；行列交叉只算一次。停机、断电或安装中会破坏该组，故障只降低故障柜自身产出，不连坐组员。

### 4.2 供电（机房级容量）

- 每台机柜有**耗电值**（GPU 最高）。机房内所有机柜耗电之和 ≤ 供电单元容量，超出的机柜无法开机；供电按槽位编号从小到大分配，玩家可手动停机保留不希望占用容量的机柜。
- **视觉规则（必须实现，是核心反馈）**：
  - 未接供电 / 容量不足的机柜：机房和机柜呈**暗灰色、无灯光**。
  - 供电正常：机房整体点亮，机柜 LED 闪烁，窗口透出暖光。
- 供电单元分级（T1/T2/T3），升级即替换，旧单元按残值回收。

### 4.3 冷却（行/列覆盖制）

- 每台机柜有**发热值**（GPU 最高）。每个格子的「受冷量」= 覆盖该格的所有冷却单元制冷量之和。
- 格子受冷量 ≥ 机柜发热值 → 正常；不足 → 该机柜**过热**：产出降低 + 故障率上升（数值见 02_economy §5.3）。
- 冷却单元两种：
  - **风冷**：便宜、制冷量低。特效：扇叶旋转 + 淡蓝色风线。
  - **液冷**：贵、制冷量高（后期解锁）。特效：管道 + 冰晶/白霜粒子。
- 布局小谜题的来源：GPU 机柜发热高，要摆在能被两个冷却单元交叉覆盖的**角格**；存储机柜发热低，放中心格。这是「方案 B」的全部深度——刻意保持简单。

### 4.4 生命周期与老化

状态机（寿命进度 = 已运行时间 / 额定寿命）：

```
建设中 → 全新期(0~60%) → 老化期(60~90%) → 衰退期(90~100%) → [报废残料]
                              │                │
                              └── 正常退役 ◀───┘   （玩家主动收割；科技可在 95% 自动执行）
```

| 阶段 | 产出效率 | 故障率 | 视觉 |
|---|---|---|---|
| 全新期 0~60% | 100% | 基础值 | 外观崭新 |
| 老化期 60~90% | 100% → 70% 线性衰减 | ×3 | 外墙污渍、锈斑，图标出现「⚠ 老化」 |
| 衰退期 90~100% | 70% → 40% | ×6 | 明显破败、冒黑烟颗粒，红色警告常驻 |
| 报废 100% | 0，合约自动终止 | — | 变废墟贴图；免费清理并回收折价残料 |

- **正常退役**：老化期起可随时主动退役，回收金 = f(建设成本, 剩余寿命) + 外挂件/机柜残值（02_economy §5.4），且始终严格高于报废残料。越早退回收越多、但放弃剩余赚钱时间。
- **报废残料**：清理免费，返还建设成本 5% + 外挂件 10% + 机柜 50%，只会少收成，不会倒扣现金。
- **自动退役科技**：时代 2 花 $15,000 一次解锁；机房达到 95% 寿命时自动收割，离线也生效，并原价退回该机房未完成的建设任务。
- 每座机房独立计龄（D17）。

### 4.5 稳定性故障（随机事件）

- 每台**运行中**的机柜按泊松过程随机故障（老化、过热会放大 λ）。
- 故障机柜：保留 40% 产出，冒烟/火花特效，机房卡片上出现红色扳手角标；4 现实小时后工程师免费自动修好。
- 处理方式三选一：
  1. **派修**：花小额现金，等待 10~30 现实分钟（工程师小人动画），用于提前恢复满产。
  2. **广告立修**：看激励视频立即修复（广告位 #2）。
  3. **钻石立修**：少量钻石立即修复。
- 未处理的故障不会扩散，也不会永久停产；离线跨过自动修复点时，修复前后分别按 40%/100% 精确分段结算。

## 5. 机型（种什么菜）

| 机型 | 定位 | 特征 |
|---|---|---|
| 计算型 | 土豆（稳、平衡） | 成本/耗电/发热/收益全中等，所有客户都要 |
| 存储型 | 玉米（慢、稳） | 便宜、低耗电低发热、收益低但几乎不受行情波动影响 |
| GPU 型 | 黄瓜（贵、暴利、娇气） | 昂贵、高耗电高发热、上架周期长；行情好时收益爆炸，行情差时大跳水 |

- 上架也有周期（分钟级计时器），可加速。
- 机柜可随时下架（回收 50% 购置成本），为切换客户/行情腾格子。上架使用机房内独立计时器，单机房可并行安装 2 台，不占机房/附件/网络的全局建设队列。

## 6. 客户与行情（卖给谁）

### 6.1 合约模型

- 合约以**机房**为单位：一座机房同一时间只服务一类客户。
- 签约时把「当前时代基线 × 签约时已生效事件」在整个合同期内做精确的时间加权平均后**锁价**，不含日噪声、也不把预告事件算入；合约期内收入只使用锁定倍率，实时行情仅影响下一次签约/改签。短约能更集中地吃到短期爆发，长约会把事件摊薄，形成“吃爆发签短约、求安稳签长约”的真实期限决策。
- 合约期 = 6 游戏月（12 现实小时）；到期瞬间无缝自动续约并重新锁价，同时保存一枚不过期、不叠加的「免费改签」资格。玩家不处理也不会停收；提前改签则支付月收入 25%、最低 $25。
- **询价单**：教程完成且累计建成 2 座后，客户会按 4–8 游戏月间隔带条件来单，最多保留 3 张。询价永不过期、没有倒计时；满足机柜/网络/关系/园区条件后可选机房接单，获得 ×1.20–×1.40 报价溢价、0.5–1.5 个月预估收入的签约金和关系进度。婉拒无惩罚，仅该槽位等待 2 游戏月再补位。

### 6.2 四类客户

| 客户 | 偏好机型（适配系数高） | 行情波动性 | 解锁 |
|---|---|---|---|
| 互联网厂商 | 计算型 | 低 | 开局 |
| 挖矿 | GPU、计算型 | **极高**（暴涨暴跌） | 开局（新手期的刺激来源） |
| 云厂商 | 计算+存储混合（机型多样性有加成） | 中 | 时代 2 |
| GPU 厂商（AI 公司） | GPU | 高（长牛短熊） | 时代 2，网络 ≥ L2 |

### 6.3 行情事件系统

- 每类客户有一个**行情价倍率**（围绕 1.0 波动），由「时代基线 + 随机事件」驱动；它是新签报价，不追溯改变已有合约。
- 事件按加权随机在事件池中抽取，同一时间最多 2 个事件生效。事件示例（完整表见 02_economy §6）：
  - 「AI 大模型热潮」：GPU 厂商 ×3.0，持续 3 游戏月
  - 「矿难」：挖矿 ×0.2，持续 6 游戏月
  - 「大厂自建机房」：云厂商 ×0.6，持续 4 游戏月
  - 「电商大促」：互联网 ×1.5，持续 1 游戏月
- UI：主界面顶部滚动「行业新闻」条 + 独立行情页（四条客户价格曲线，近 2 游戏年）。
- 事件在生效前 1 游戏月（2 现实小时）会有「新闻预告」，给玩家调仓窗口——这是策略感的核心来源。
- 事件池含三条低权重稀有行情：主权 AI 训练（GPU ×5）、算力饥荒（全客户 ×1.8）和合规归档（互联网/云存储需求 ×3）。三档期限都先按事件剩余时长精确折算；12 月战略约签约及续约的折算值再封顶 ×2.5，避免把长尾报价无风险锁满全年。

## 7. 时代演进（长循环之一）

| 时代 | 解锁条件（累计总收入） | 解锁内容 |
|---|---|---|
| 1. 托管时代 | 开局 | 集装箱/标准机房、风冷、计算/存储机柜、互联网+挖矿客户 |
| 2. 云计算时代 | 详见 02_economy §7 | 大型机房、GPU 机柜、云厂商+GPU 厂商、液冷（前置：大型机房） |
| 3. AI 时代 | 详见 02_economy §7 | 超大规模机房、高密 GPU 机柜、AI 专属大合约事件、液冷 T2 |

- 时代切换伴随一次全屏演出（新闻头条式：「云计算时代来临！」）和行情基线永久调整（如时代 3 中 GPU 基线上移）。
- 科技页可逐级扩编工程部，把全局建设队列从 2 条提升至 3/4/5 条；价格与门槛见 02_economy。扩编随上市重组重置，每局需要重新购买，使带回的新公司现金真正转化为建设速度。

## 8. 转生：上市重组（长循环之二）

- **解锁条件**：累计建成 ≥ 20 座机房（含已退役）。达成前，入口完全隐藏（D19）。
- **效果**：
  1. 所有机房、外挂件、地块按当前净值折现，一次性加入现金余额；
  2. 盘面重置：回到只有初始地块的状态（时代进度、网络等级**保留**——重刷这些太磨人）；
  3. 获得永久「品牌倍率」加成（公式见 02_economy §8），随净值规模递增。
- 定位：数值趋平时的续命手段，也是「爆数字爽感」的主要来源。

## 9. 欠费与银行接管

- 持续性支出：机房维护费（按游戏月扣）、故障维修费。
- **预警阶段**：现金不足以支付当期维护费 → 进入「欠费」状态：全部机房产出减半、界面持续提示银行催收，在线累计 6 现实小时作为处理期（可退役资产回血、可看广告救急金）；离线暂停催收计时。
- **银行接管**：到期后按建成时间从老到新，以正常退役价值的 70% 变卖运营中机房；所得优先抵债，债清即停。全部卖完仍不足则核销剩余欠款；若已无运营中机房，现金补足到 $5,000。
- 接管只重整资产，不清档：地块、时代、网络、科技、钻石和未变卖机房全部保留，结算页关闭后继续经营。设置页仍保留玩家自愿的「重新创业」。
- P02（钻石重组自救）默认关闭，见 00_decisions。

## 10. 离线与回归

- 游戏时钟以真实时间为基准，离线继续推进建设、行情、合约自动续约、免费自动修复与老化。
- **离线收益**：按离线时长结算，上限 8 小时（内购扩到 24h）。回归弹窗呈现收益总额、广告 ×2 与大事记（自动续约/免费改签、自动修复、老化、自动退役等）。
- 离线永不让资产比离开时更糟：未购自动退役者到 100% 时冻结在 99.9% 等玩家回来；已购者在 95% 自动收割入账；欠费催收计时暂停；故障会免费恢复。

```

│ 顶栏: $现金 | 💎钻石 | 时代/日期    │
│ 新闻滚动条(行情事件)              │
├─────────────────────────┤
│                         │
│      主地图 (可滚动缩放)          │
│   [机房][机房][工地][待售地块]     │
│                         │

├─────────────────────────┤
│ 底栏: 建设 | 行情 | 科技 | 商店 | 设置 │
└─────────────────────────┘
```

五个一级页面：
1. **主地图**（默认）：地块总览、建设入口、故障角标。
2. **机房详情**：3×3 网格、外挂件槽、合约面板（当前客户/收入/到期时间/换约按钮）、寿命条与退役按钮。
3. **行情**：四客户价格曲线 + 事件列表（进行中/预告）。
4. **公司**：路线图、网络/科技升级、企业典藏、董事会专长四个页签。
5. **商店**：钻石、礼包、去广告、离线上限扩容。

## 12. 新手引导（第一个 24 小时）

1. 开场 30 秒：导师角色（戴安全帽的工程师「老高」）引导建第一座**集装箱机房**（建设 5 分钟）→ 挂供电（点亮瞬间是第一个「aha moment」，配灯光音效）→ 上架 2 台计算机柜 → 签互联网客户 → 看到金币流入。
2. 第 1 小时：解锁冷却教学（上架第 3 台机柜后出现过热警告 → 引导挂风冷）→ 引导买第二块地。
3. 第 1 天内：集装箱机房走完整个生命周期（1 游戏年寿命）→ 老化 → 引导正常退役拿回收金 → 引导建标准机房。**至此核心循环全部教完**，后续系统（行情毁约、液冷、时代）按解锁节点弹提示。

## 13. 公司成长与策略闭环

- **公司路线图**：六个永久里程碑覆盖首座机房、六座扩建、时代 2、四类客户、网络 L4 与首次传承。进度来自真实经营，完成后可随时领取钻石，不设置倒计时。
- **园区定位**：每个园区免费选择托管枢纽、云服务枢纽、AI 算力集群或多元园区；只有真实机柜/客户布局达标才激活小幅收入加成，定位可免费更换。
- **客户关系与期限**：服务时长永久累计，新客户→熟悉→信赖→基石只升不降；签约时可选灵活 3 月、标准 6 月、战略 12 月。战略约需熟悉关系，期限越长锁价越久但不保证市场最优。
- **行情决策复盘**：行情页记录签约时倍率、当前倍率和对应月收入，帮助玩家理解一次选择的后果；不追溯改变已签收入。
- **中期拉动目标**：永久询价单把客户需求转为具体布局目标；成组加成让同一 3×3 棋盘同时考虑冷却覆盖、客户多样性和同类成线，而不是只塞单一最贵机柜。
- **后期现金出口**：工程部扩编用现金换建设并发，且转生后重置，连接“本局盈余—下一局重建速度”的闭环。
- **董事会专长**：每次上市重组获得 1 个永久点，可分配到建设、运营、商务三条线并免费重置；加成幅度小，表达经营风格而非硬门槛。
- **企业典藏与公司纪念册**：设施、客户、行情、传承按实际遇见点亮；传承前保存本局营收、净值和设施数，下一家公司仍可回看。它们共同形成“建设→形成专长→做合约决策→复盘→传承→留下记录→再次建设”的长期闭环。
- **范围边界**：本轮不做批量建设、批量配置和蓝图系统（D34）。
